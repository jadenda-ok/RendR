# Changelog

All notable changes to Rendr are documented here. Release notes on GitHub are
generated from this file.

## [1.1.0] - 2026-11-15

**Rendr v1.1.0 — the redesign release.**

Rendr is now a fully local, black & white Roblox companion: crosshair overlay
studio, real-time FPS indicator and FastFlags manager. No accounts, no
injection, nothing leaves your PC.

### What's new

- **Complete redesign** — Roblox-style navigation with an Overview dashboard, Update Log and About page.
- **New black & white theme** built around the geometric Rendr mark.
- **FPS indicator rebuilt** — stable smoothed readings, one capture session at a time, and a proper wait for the Windows permission prompt.
- **Bloxstrap support** — FastFlags now reads Bloxstrap-style files with string values like `"True"` or `"60"`, and backups are validated before restoring.
- **Overlay fixes** — no more empty overlay at launch; temporary previews now revert to your crosshair automatically.
- **Hotkey fix** — the cycle-crosshair hotkey now always advances from your active crosshair.
- **Preset fixes** — presets can be reused without creating duplicate profiles.
- **Sign-in removed** — Roblox login is gone. Rendr is fully local.

### Install

1. Download `rendr-setup.exe` and run it.
2. Windows SmartScreen may warn because the app is unsigned — choose **More info → Run anyway**.
3. Launch Rendr from the desktop shortcut or Start menu.
